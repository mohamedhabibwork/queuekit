QueueKit

Typed queue, messaging, pub/sub, and stream infrastructure without losing provider-native capabilities.

Runtime-neutral core for Node 20+, Bun, and Deno 2+.

npm install @mohamedhabibwork/queuekit kafkajs

What ships in v0.1

BullMQ, Kafka, RabbitMQ, Redis Pub/Sub and Streams, NATS Core, Amazon SQS, typed registries, a lazy multi-provider manager, middleware, codecs, a custom-provider API, and an in-memory test provider.

Design

Use one consistent lifecycle and message model, while keeping provider-native options under native. Capabilities describe what each broker actually supports; QueueKit does not claim universal exactly-once delivery.
